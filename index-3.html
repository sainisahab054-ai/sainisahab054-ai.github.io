SS Report Master

SS Report Master is a private business tool that lets authorised staff get accounting reports from their own office Tally server, on a Windows PC or an Android phone.

How it works

  • The office runs SS Report Master Server on its Tally PC and decides which companies, reports and ledgers each team may see.
  • The office shares a Google Drive folder with its users. The user app places a report request in that folder.
  • The server prepares the report from Tally and puts the Excel or PDF file back in the same folder. The user app saves it on the user's device.

Available reports

Ledger account, group ledger, trial balance, sales / purchase / debit note / credit note registers, voucher register, day book, voucher view and print, stock summary, inventory ledger and inventory book — only those allowed by the office.

Google sign-in

The Android app asks the user to sign in with Google so that it can open the Google Drive folder that the office has shared with that user. Read the Privacy Policy for details.

SS Report Master is used internally by the businesses that set it up. It is not sold to the public.
